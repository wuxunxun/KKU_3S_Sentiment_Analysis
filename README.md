# KKU'3S Sentiment Analysis Project

## Project Introduction
This is a group course project for the **KKU'3S campus second-hand trading platform**.

The main purpose is to construct a sentiment discrimination module to identify positive and negative emotional tendencies of platform user comments.

We will train and test multiple candidate models based on the TweetEval dataset, compare the overall performance of each model, and select the optimal model reserved for deployment on the KKU'3S platform later.

### Tools Adopted
- Hugging Face Library: Data processing and model tuning
- Weights & Biases: Record full experimental data and training metrics
- Development Language: Python
